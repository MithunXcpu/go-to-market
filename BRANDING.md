# Branding foundation — Watermelon universe

## Decision

All business POCs use **Watermelon UI** as the design system.

## Why this universe

- Open-source, copy-paste architecture (own the code)
- 260+ production React components / blocks / dashboards
- Stack: React, TypeScript, Tailwind CSS v4, Radix UI, Framer Motion, shadcn-compatible
- Matches the polished startup look for pitch assets and product UI

## Canonical links

1. https://ui.watermelon.sh/
2. https://github.com/WatermelonCorp/watermellon-registry
3. https://github.com/WatermelonCorp/watermelon-platform

## Do / don't

- **Do** pull components via registry / shadcn CLI into the POC
- **Do** match Watermelon block/dashboard compositions for marketing screens
- **Don't** invent a parallel design system for Reflector
- **Don't** wait on the pitch deck to start UI — look is locked; product story is not
